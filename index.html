Setup instructions + script (do this once, for the whole team)
1. Go to sheets.google.com → create a blank spreadsheet (name it e.g. "Chosen Leaderboard").
2. Extensions → Apps Script → delete the default code, paste in the script below.
3. Deploy → New deployment → Web app → Execute as Me, Access Anyone → Deploy → authorize it.
4. Copy the Web app URL (ends in /exec).
5. Paste that URL into the SHEET_API_URL constant near the top of this file's <script> tag, replacing the empty quotes.
6. Save the file and send it to your whole team — everyone who opens it will create their own login, and every submission syncs to the same sheet automatically.
7. If you ever update the script's code, redeploy via Deploy → Manage deployments → edit → Version: New version to keep the same URL.
