Setup instructions + script (do this once, for the whole team)
1. Go to sheets.google.com → create a blank spreadsheet (name it e.g. "Chosen Leaderboard").
2. Extensions → Apps Script → delete the default code, paste in the script below.
3. In your Slack app's settings (api.slack.com/apps → your app), go to OAuth & Permissions. Under Bot Token Scopes, add chat:write (add chat:write.public too if you want it to post to public channels without being invited first). If you add a scope after the app was already installed, click Reinstall to Workspace at the top of that page. Copy the Bot User OAuth Token (starts with xoxb-).
4. In Slack, open the channel you want sales posted to and type /invite @YourBotName so the bot is allowed to post there (skip only if you added chat:write.public and the channel is public). Then get that channel's ID: right-click the channel name → View channel details → scroll to the bottom → copy the Channel ID (starts with C).
5. Paste the bot token into SLACK_BOT_TOKEN and the channel ID into SLACK_CHANNEL, both near the top of the script below. (Optional) Paste this page's published link into APP_URL so the Slack post links back to it.
6. Deploy → New deployment → Web app → Execute as Me, Access Anyone → Deploy → authorize it.
7. Copy the Web app URL (ends in /exec).
8. Paste that URL into the SHEET_API_URL constant near the top of this file's <script> tag, replacing the empty quotes.
9. Save the file and send it to your whole team — everyone who opens it will create their own login, and every submission syncs to the same sheet, posts to Slack, and lands in that agent's own Production Tracker automatically.
10. If you ever update the script's code (for example, upgrading from an older version that didn't have Production Tracker support), redeploy via Deploy → Manage deployments → edit → Version: New version to keep the same URL — everyone keeps working with zero changes on their end.
